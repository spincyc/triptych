# Start here

This is a planning-review package, not a public-cutover payload. Begin with
`CUTOVER-DECISION.md`, then read `ROUTE-MAP.md`,
`STATE-COMPATIBILITY.md`, and `PROPOSED-CUTOVER.patch` together.

The selected architecture is same-path source promotion behind unchanged
canonical filenames. The patch is deliberately unapplied and its header
prohibits execution until the independent reviewer dispositions the enumerated
public-contract choices and the patch is regenerated accordingly.

Canonical Day and Propers, public navigation, accepted candidates, and the
visual oracle are byte-unchanged. Public navigation and public cutover remain
unauthorized.
