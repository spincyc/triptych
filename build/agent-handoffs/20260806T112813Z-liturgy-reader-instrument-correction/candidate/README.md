# Runnable candidate

This is a compact private-preview subset containing the two visual-reset pages,
their local browser assets, both selected missal structures, 2026 calendars,
and the held Douay-Rheims fragments used by the review states.

From the handoff root run `python3 -m http.server 8000`, then use the URLs in
`../START-HERE.md`. No external request is required. This candidate is noindex,
unlinked, non-public, and not a replacement for production Day or Propers.
