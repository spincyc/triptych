# Visual decisions

- Keep Instrument's cue grid and continuous-action hierarchy. Do not import
  Folio's centered Ordinary or Reader's application chrome.
- Read removes the ritual gutter and uses one centered 39.75rem axis for
  identity, headings, references, and prose.
- Missal retains the cue grid but removes the dead identity-to-rite interval.
- The desktop action system is a square, transparent, shadowless ruled rail
  aligned just outside the 896px ritual plane. The mobile system is an opaque
  edge dock with a top rule and safe-area ownership.
- Instrument's generic circular T becomes a CSS-only three-stroke triptych
  device. The visible progress dash is removed because it was not intelligible;
  internal semantic progress remains live.
- Roman uncompiled text moves unchanged into the existing identity-level
  `role="note"`; the duplicate generic notice is displaced. Postconciliar
  missing-language nodes keep their exact text inside quiet inline groups.
- Speaker changes remain explicit but use quiet gray; named ritual cues retain
  the red gutter. Closely related spoken elements tighten without changing DOM
  order or source text.
- At 320px, division titles balance deliberately with no hyphenation or orphan
  fragment. End-of-rite provenance remains subordinate and complete.
