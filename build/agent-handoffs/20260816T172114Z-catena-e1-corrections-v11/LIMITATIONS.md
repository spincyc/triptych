# Limitations — what this package does not prove

Each of these is stated at full strength. None is softened, and none is
offered as a reason to accept anything.

## 1. The scope is one correction, and this head is not a candidate for acceptance

This head closes the exported claim boundary over its MEMBERS, replaces one
over-asserting sentence with a weaker true one for the states that establish
less, completes the late terminal vector to all 36 guarded fields, gives the
packaged request journal its ownership, and corrects the package protocol —
and nothing else. A review of this package can accept the claim closure at
most. **It cannot accept E1**, and this package claims nothing wider.
`UNRESOLVED-BLOCKERS.md` enumerates what stays open.

## 2. The request sink proved is the harness's stubbed `fetch` seam

Every request journal in this package comes from the replay harness's
stubbed `fetch` — the same seam, driven the same way, that the earlier
independent reviews used to prove their defects. The prewarmed and
genuinely late scenarios exercise the production path-keyed body cache and
the real deferred completion through that seam, and the ownership journal
and `history.state` capture are projections of that same shim. That is a
claim about which addresses the production files hand to the network
boundary, when, and under which phase. **It is not a network capture from a
real browser session.** The browser gate did run in real Chromium at both
ends, over the built site, but it asserts the shared shell's generic
contract, not this route's request journal.

## 3. The own-data closure covers the claim's contract, not the wide contracts

The descriptor-based reading is applied to the CLAIM's small fixed contract
— `stated`, `said`, `trail` — and to the members that compose a request: the
spine's own `text_prefix`, the carried `text_path`, the fragment's `id` and
`source`, the edition join and the extent members. **The wide fragment and
edition contracts remain field-validated rather than prototype-hardened.**
That is a deliberate boundary of this correction, not a completed hardening,
and a reviewer should read it as unfinished work with a stated edge rather
than as a closed surface.

## 4. Fail-closed has a cost, and the cost is not hypothetical

A claim whose three-member contract is partly written above it fails closed.
The alternative — ignoring inherited values and adjudicating on the own half
— was rejected because the route's own directions require that an own valid
state beside an inherited refusal marker make no request. The price is that
a polluted object prototype closes every row on the page rather than one.
This package does not argue that price is correct; `REVIEW_REQUEST.md` asks.

## 5. The pipeline that built this package is not under version control here

The pipeline that assembles, sanitizes, seals and verifies this package
lives in a workspace directory that **is not a git checkout in this
workspace**. The P8 trust anchor is therefore recorded by path and by
per-tool SHA-256 rather than by a commit: the verification transcript names
the out-of-archive directory it ran from and prints the trusted and the
shipped digest of every tool it used, and fails hard when they diverge. A
reviewer who wants a commit-pinned anchor does not have one here, and should
read the per-tool digests as the whole of the binding. The anchor is outside
the archive but it is not independent of the party that built it, and the
transcript says so verbatim.

## 6. Screenshots: six of eight adversarial pairs are byte-identical by design

The adversarial capture set is eight before/after pairs — four fragment
text-states at two viewports each.

- **Six of the eight pairs are byte-identical.** The absent, present-valid
  and refused states render exactly as the parent rendered them, at both
  viewports, and the two PNGs of each such pair are the same bytes. That is
  the evidence that this correction changed only the state the review found
  wrong; it is not a failure to capture a difference.
- **Two pairs differ**, both of them the unestablished state: 11,392 of
  1,296,000 pixels at 1440x900 and 13,639 of 334,836 at 393x852. The parent
  renders the refused sentence there; this head renders the unestablished
  one. The differing region is larger than the sentence because the content
  below it reflows.

Nothing here asserts a visual difference that was not captured, and nothing
here asserts what an uncaptured image would have shown.

## 7. Three capture classes were not produced

- **No print capture.** The changed sentence lives inside a `<details>`
  disclosure that a print stylesheet does not open by itself, and the
  roadmap's print item is a check rather than a required image for a copy
  correction. Nothing in this package is print evidence.
- **No no-JavaScript capture.** With scripts off, the Catena route serves a
  static "About this page" block and no fragments at all, so nothing that
  could carry a no-text sentence is on the page in either checkout and an
  image would show the same thing twice. The gate's own
  `no-script-static-truth` phase covers that route as a check.
- **No keyboard-focus capture.** None was produced, and **the capture
  record states no reason for its absence**. This package therefore carries
  no focus-visible raster evidence for the changed row, and a reviewer who
  needs it must ask for it. The shipped browser-gate reports do carry a
  `focus-indicator-differs-from-resting` phase over all 171 pages, but that
  is a check of the shared shell's generic contract, not an image and not
  evidence about this row.

`screenshots/INDEX.md` is the capture lane's own record of all three bounds;
this section reproduces them and adds the keyboard-focus gap, which that
record does not mention.

## 8. The screenshots were captured at the first of this lane's two commits

Every head-side image was captured at `3b93f74f032e74de9a50c1e2f1b35aa5b567f8d8`,
the production correction, and `screenshots/capture-metadata.json` names
that commit. The exact head of this lane is
`0255b84996e1dc24da3ce75ac318c4f774b7957c`, one commit later. The two differ
only in durable records — `PROJECT-WORK.md`,
`guidance/corpus-browser-roadmap.md`,
`guidance/corpus-browser-master-plan.md` and `promised-deliverables.toml` —
and the four Catena files a browser loads are **byte-identical** between
them: `src/web/browser/catena/catena.js`,
`src/web/browser/catena/catena-model.js`,
`src/web/browser/catena/catena.css` and
`src/web/browser/catena/index.html`. That byte identity is the reason the
captures bind to the exact head. The images are not relabelled as taken at
the head, because they were not.

## 9. The parent-side battery figures are inherited, not adjudicated

Full discovery, the `make` targets and the browser gate fail at the parent
and at this head in the same identities. `make -k check` exits 2 on the same
four targets at both endpoints — `check-web-editions-current`,
`check-release-bindings`, `check-tool-registry` and `check-examples` — all
four **inherited**, measured at both ends. This package proves the sets
match under the named volatile exclusions; it does not prove the sets are
acceptable. They belong to their separate owners. Every such figure is
labelled inherited; a pinned expected value is called a vector, and neither
is called a baseline.

## 10. One measurement is only valid in isolation, and the raced run is discarded

Full discovery run CONCURRENTLY with `make -k check` reports **250 errors
instead of 13**, because that target builds and then removes
`build/.web-current` and the public site underneath the tests. Every figure
this package states comes from an isolated, ledgered run; the raced run is
recorded as discarded and is used for no claim. This is stated as a
limitation because it is the shape of an error this package came close to
making.

## 11. The 36-field vector is complete for this guard, not for the route

The late terminal vector states an expected value for all 36 fields the
guard currently carries, at both ends of the release, and a coverage test
fails if the guard widens without the proof widening with it. That is a
claim about the guard as it stands. It is not a claim that 36 fields are all
the sinks this route has, and the broader terminal proofs for the other
corrected classes remain open in `UNRESOLVED-BLOCKERS.md`.

## 12. Judgements are not derivations

Every figure a machine could derive is derived into `claims.json`. Whether
the conservative sentence is truthful and neutral enough, whether
fail-closed is the right disposition for a partly-inherited contract,
whether the 36-field vector is now complete, and whether the corrected
package protocol answers the review's findings are **judgements**.
`REVIEW_REQUEST.md` asks them instead of asserting them.
