# Indexing and metadata evidence

Retained candidate source pages contain exactly:

`noindex, nofollow, noarchive, nosnippet, noimageindex`

The directive exists in source before JavaScript. Candidate runtime titles and
visible failures/status are route-neutral. Candidate/oracle routes do not carry
public canonical or Open Graph entrance advertising.

Canonical `day.html` and `index.html` remain the legacy indexable sources in
this phase. The unapplied patch omits robots metadata from their proposed
Instrument markup, uses source titles `Day` and `Propers` so the builder appends
` · Triptych` exactly once, and supplies route-neutral descriptions. The
existing `/liturgy/` Pages alias remains the accepted alias for the same
Propers document; no redirect or new build-pipeline canonical-link mechanism is
introduced.
