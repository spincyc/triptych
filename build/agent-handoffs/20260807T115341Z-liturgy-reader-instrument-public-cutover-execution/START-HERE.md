# Start here

This package records the executed same-path public cutover of Triptych's accepted
Liturgical Instrument readers. Canonical `/liturgy/day.html` and
`/liturgy/index.html` now serve the accepted readers without redirecting.

Begin with `HANDOFF.md`, then inspect `LIVE-VERIFICATION.md`, `CACHE-WINDOW.md`,
the machine-readable results under `evidence/`, and the original-pixel images.
The cutover is deployed and locally/live verified, but remains pending the nine-
question independent post-deployment acceptance in `REVIEW_REQUEST.md`.

Public navigation was not changed. Retained candidate and visual-oracle routes
remain present and noindex. Cleanup and redesign remain unauthorized.
