# Rollback

No rollback trigger fired during execution. If independent review discovers a
material canonical-route, state, source, accessibility, deployment, or mixed-
cache failure, use an ordinary revert:

```sh
git revert 9b5f21c0ca26bf02af03d207ddd2617021e16fb3
git push origin main
```

Do not rewrite history. Require Pages success for the exact revert SHA, HTTP 200
on canonical Day/Propers, restoration of the legacy route behavior/hashes, an
immediate cache-bypassed pass, and another pass after more than 600 seconds.
The compatibility-closed candidates and oracle remain available and are not
part of this rollback unless a separate defect independently requires it.
