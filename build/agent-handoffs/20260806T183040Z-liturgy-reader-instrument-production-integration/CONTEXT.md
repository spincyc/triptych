# Context

Independent Round 1 accepted Liturgical Instrument as Triptych's production
visual foundation and authorized production-integration execution. This pass
moves that presentation into the existing unlinked Day and Propers
production-reader candidates while preserving their existing public-alpha
publication policy and accepted state, adapter,
renderer, seating, focus, semantic-location, and race owners.

The smallest seam is a last-loaded, candidate-scoped
`reader-instrument.css`. Stable masthead/action hooks were added to the two
candidate pages. The only JavaScript changes are generation-safe presentation
composition: exposing the already-authoritative committed Day mode, moving an
existing uncompiled notice into the identity coverage region, and grouping
direct renderer-owned Ordinary absence notes. No text or semantic event is
invented or removed.

The accepted visual-reset prototype remains unchanged as the oracle. Public
`liturgy/day.html` and `liturgy/index.html`, public navigation, and public
cutover remain outside this package.
