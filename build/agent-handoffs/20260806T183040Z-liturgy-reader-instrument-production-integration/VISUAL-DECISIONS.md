# Visual decisions

The accepted visual system is carried into production without redesign:

- one 39.75rem/636-pixel Read axis at 768×1024;
- wide Missal cue grid and coherent mobile stacking;
- early principal liturgical text;
- one compact identity-level coverage statement and grouped inline absences;
- restrained three-stroke masthead device;
- external ruled desktop rail, direct opaque square edge dock below 72rem, and
  labeled 2×2 dock at extreme root-font reflow;
- whole labels, large targets, visible focus, forced-colors and reduced-motion
  support;
- Day/Date and Propers/Browse as distinct entrances to one product.

Propers Browse retains its production selector. The prototype title filter is
not integrated because search is explicitly out of scope. This is the only
intentional presentation-content difference in the paired matrix.
