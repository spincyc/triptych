# Authoring Help

Route a proposed creation, revision, audit, or publication task to the narrowest applicable skill and profile without changing repository files.

## What to provide

Treat the user's complete request and thread context as controlling input, whether it follows the suggestions below or is entirely free-form.

- A document idea, existing title or path, problem to solve, or desired publication outcome.
- Any known rite, edition, language, territory, calendar, jurisdiction, source corpus, or as-of date.
- Any free-form context, desired emphases, guides, exclusions, limits, staging, or review concerns.

## Preflight

1. Read `../../references/conventions.md` completely and apply it.
2. Inspect the README catalog and profile routing in `AGENTS.md`.
3. If an existing target is named, locate it and identify its controlling profile without editing it.

## Plan

Classify the request by actual object and source needs, not merely by words in the title. Identify any secondary profile that genuinely governs a distinct part of a mixed work.

## Actions

Recommend exactly one primary skill when possible:

- `$triptych-authoring:article` for discursive faith, theology, canon-law, or mixed essays;
- `$triptych-authoring:novena` for a full novena and condensed prayer book;
- `$triptych-authoring:mariology` for Rosary, dogma, devotional, or general Mariological references;
- `$triptych-authoring:apparition` for apparition events, messages, judgments, or authority-qualified corpora;
- `$triptych-authoring:proper-1962` or `$triptych-authoring:proper-postconciliar` for variable liturgical formularies;
- `$triptych-authoring:ordinary` for stable Mass texts, ritual sequence, or cross-edition Order-of-Mass exposition;
- `$triptych-authoring:assembly-1962` for calendar, precedence, Mass-class, commemoration, or formulary-assembly rules;
- `$triptych-authoring:sacrament` for the canonical sacramental treatise and derived consumers;
- `$triptych-authoring:revise` for a cross-cutting change to an existing document;
- `$triptych-authoring:audit` for report-first or explicitly authorized remediation;
- `$triptych-authoring:publish` for completed source that needs artifact and catalog handling.

List the minimum blocking input and the most useful optional input for the selected skill. Treat the user's existing prose as valid free-form input; do not force it into a form.

## Verification

Confirm that the recommended skill's profile owns the requested object and that no existing specialized profile has been bypassed.

## Summary

Return the selected skill, a one-sentence reason, the information already supplied, and the few remaining inputs that would materially improve or unblock the work.

## Next Steps

Show one ready-to-run skill mention using the user's own context. Do not edit files or begin research until the user invokes or otherwise authorizes the selected workflow.
