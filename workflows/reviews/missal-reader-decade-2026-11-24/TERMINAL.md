### Reproduce the dated checks

Run the verifier from the repository with Node on PATH, the lectern Python dependencies installed, and a generated product directory containing `structure/`. It derives the expected appointments from the calendar, rubrics and formulary index, follows the actual Day choices through the terminal bridge and checks the resulting styled text and Contents order. The JSON output lists missing and unexpected appointments, per-date errors and measured adapter and formatter times. A discrepancy gives a nonzero exit status.

```sh
for calendar in roman-1962 postconciliar; do
  for mode in read missal; do
    python workflows/reviews/missal-reader-decade-2026-11-24/verify_terminal.py \
      "$PRODUCT_ROOT" --calendar "$calendar" --mode "$mode" \
      --first 2026-11-24 --last 2036-11-23
  done
done
```
