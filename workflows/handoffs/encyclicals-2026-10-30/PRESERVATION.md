# Preserved deferred-data archive

The five original `deferred-data.zip.part-*` chunks are retained as exact
immutable release assets in
[Triptych artifacts](https://github.com/spincyc/triptych-artifacts/releases/tag/review-handoffs-2026-11-02-v1).
`preservation.json` records every original logical path, size and SHA-256,
and the hash of the complete concatenated ZIP. Download and verify the five
parts before following the historical restore instructions in this handoff.
Concatenate them in numeric order; the expected ZIP is 192,803,781 bytes.

The archive contains 91 historical PDF members. It was moved intact so the
source tree carries neither direct nor archived PDF payloads from this handoff.
The existing handoff, inactive records and review limits remain historical
evidence; this storage change grants no source, editorial or publication
approval and changes no archive member.
