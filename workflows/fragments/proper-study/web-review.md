# Review the canonical web conversion

Read the generated canonical Markdown at `build/web/{provider}/{proper}.md`
and compare it to the reviewed canonical study source and evidence. Check the
complete text, interpretation boundaries and four senses, meaningful heading
hierarchy, tables or replacements, exact source notes, readable notation,
working references, and absence of TeX debris or exposed production metadata.
Use the existing web-rendering preview when needed to judge presentation; do
not claim a browser review from Markdown inspection alone.

Identify the actual conversion hash from `research/web-artifact.json` in the
review summary. The synthesis and homily companions have readers of their own,
converted from their own entrypoints; this review covers the canonical study,
and a concise or homily excerpt must not replace it. Use `WEB-` findings with
`publication` for conversion defects, `study` for source writing, or `research`
for evidence. Do not edit the conversion you are reviewing. PASS records these
exact bytes as inspected; the site converts the same sources at build time, and
a changed conversion requires a new review.
