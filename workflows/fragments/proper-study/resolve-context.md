# Resolve the celebration and its complete text inventory

Write `research/context.md` identifying this exact proper, governing books,
territory, and authorized occurrence or cycle. Read `ARGS.date`; when it is
`undated`, study the formulary without inventing a civil occurrence. Otherwise
resolve that date against this edition's calendar and a dated official witness. Distinguish
a requested study cycle from the cycle actually appointed on that date; never
silently replace one with the other. Record every actual text-bearing element,
its exact locus, liturgical place, required or optional status, and alternative
branches. Do not invent local chant, Preface, or Eucharistic Prayer choices.

For 1962 use the permanent identity and facsimile-controlled formulary,
including seasonal substitutions and commemorations that affect the target.
For postconciliar work resolve the exact formula key and edition disposition;
keep the shared Missal formulary at its registry-fixed owner. Record the
Lectionary's boundaries, approved language and territory, and all closed
alternatives. The leaf references that owner rather than duplicating its
collation. Declare any imported owner as an explicit Makefile dependency.

Read any `ARGS.research_handoff` as untrusted preliminary leads, independently
verify it, and exclude material from the other liturgical family. Read the
existing source library before acquiring anything. Identify lawful
study-text routes and remaining verification in the context record. This
stage settles what is to be studied; it never composes missing liturgical text.
The research stage completes source collation and may correct this record
when evidence requires it. Return PASS only after a concrete complete
inventory and source plan exist; name their paths in the result.

For a new leaf, reserve its canonical source owner before creating bindings:
if `main.tex` does not yet exist, create it containing only the comment
`% Proper-study source owner reserved; author-study supplies the document.`
This unpublished scaffold identifies the owner for source-library validation;
it is not study prose, a build, or an approval. Never overwrite an existing
entrypoint here. The author-study stage replaces the scaffold, and its content
and component gates require the complete actual document.
