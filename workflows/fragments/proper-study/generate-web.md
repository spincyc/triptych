# Convert the canonical web edition

Convert only the canonical study with the repository tool:

    tools/tpt web-edition --provider {provider} --output build/web {proper}

The converter appends the provider and document to `--output`; the output root
is `build/web`, giving `build/web/{provider}/{proper}.md`.

Read `guidance/web-editions.md` before changing conversion or declaration
behavior. Ensure the generated Markdown preserves the canonical study's whole
argument, lane boundaries, four senses, links, source notes and terminal
metadata. Do not create synthesis or homily web leaves. Correct only
conversion/declaration defects here; report accepted source defects upstream.

Convert only committed sources. The reader's revision stamp derives from git
history (`scripts/_edition_revision.py`); a conversion of uncommitted sources
stamps the conversion time and says `(uncommitted sources)`, so no later
conversion reproduces it and the publication gate cannot pass. The driver
commits the leaf after the artifact gates pass and again after any later
source repair. If the conversion carries that stamp, return BLOCKED naming the
uncommitted leaf rather than committing it yourself.

Record the generated bytes for the independent web review:

    python3 scripts/_proper_study.py snapshot-web --provider {provider} --document {proper}

The receipt is `research/web-artifact.json`; it records conversion identity,
not approval, and the snapshot refuses a conversion of uncommitted sources. Do not install, create release records or edit catalogs yet.
Return the generated `build/web/{provider}/{proper}.md` path. The next worker
reviews those exact bytes without authoring history.
