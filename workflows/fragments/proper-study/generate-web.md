# Convert the canonical web edition

Before conversion, the coordinator must commit the reviewed source and evidence
checkpoint. Workers do not commit. Confirm each edition's revision reports
`uncommitted: false` with the existing revision command, using the bare ID and
the `-synthesis` and `-homily` IDs:

    python3 scripts/_edition_revision.py show --provider {provider} --document {proper} --json

If any relevant source closure is uncommitted, report the missing coordinator
checkpoint instead of preparing review bytes. Dirty sources receive a build-time
timestamp, so two conversions can differ even when their text is unchanged.
A source repair after this checkpoint needs a new commit before conversion and
review; never replace an accepted conversion's hash to conceal a changed stamp.

Convert only the canonical study with the repository tool:

    tools/tpt web-edition --provider {provider} --output build/web {proper}

The converter appends the provider and document to `--output`; the output root
is `build/web`, giving `build/web/{provider}/{proper}.md`.

Read `guidance/web-editions.md` before changing conversion or declaration
behavior. Ensure the generated Markdown preserves the canonical study's whole
argument, lane boundaries, four senses, links, source notes and terminal
metadata. Companion readers are generated from their own entrypoints under
this same leaf; do not create separate companion source leaves or track any
generated reader text. This stage prepares the canonical conversion for cold
review; installation checks all three readers. Correct only conversion/declaration
defects here; report accepted source defects upstream.

Record the generated bytes for the independent web review:

    python3 scripts/_proper_study.py snapshot-web --provider {provider} --document {proper}

The receipt is `research/web-artifact.json`; it records conversion identity,
not approval. Do not install, create release records or edit catalogs yet.
Return the generated `build/web/{provider}/{proper}.md` path. The next worker
reviews those exact bytes without authoring history.
