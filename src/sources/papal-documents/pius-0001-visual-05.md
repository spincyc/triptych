# Pius IX Acta visual review — pius-0001 lane 05

CHANGES_REQUIRED for 7 of 21 assigned PDFs; 14 PASS. All 66 pages were individually opened at full size; zero reused pages. This report covers only lane 05 of batch `pius-0001` (newly admitted Pius IX Acta readers from volumes II and III).

## Scope and method

Each assigned page PNG from the repository's `pdf-review` raster run was opened as its own full-size image with the Read tool (1700x2200 originals). No contact sheet, thumbnail, new raster pass, text correction or date reconstruction was used. Title line, responsible issuer, date and language label were compared with the frozen metadata; headings, two-column flow, gutters, margins, glyphs, natural source closing, historical notes and terminal apparatus were inspected.

As a locating aid only, extracted PDF text was scanned for short standalone lines, and each suspicious line was traced to the canonical OCR artifact line ranges recorded in the frozen manifest, to tell source page furniture (folios, gathering signatures) from literal mid-page OCR noise. Every finding below was confirmed on the opened page image. The boundary-reviewed-series ruling applies: a folio, signature or running head left in the body is blocking, and so is note text fused into a body line.
