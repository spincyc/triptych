RETRIEVED -- In Festo Omnium Sanctorum (1 November), 1962 Missale Romanum, with the
commemorated orations of Dominica XXIII post Pentecosten
Unedited finding aid. NOT publication text. Optical-reading errors are preserved deliberately.

Four machine pulls follow. None controls any published wording. Every Latin form in
propers/verified.md was read on page images: the 1962 facsimile at 200 and 400 dpi, the
Mame 1922 and Pustet 1862 extracts at 400 dpi. The pulls are kept so that a later reader
can see what each text layer gives and where it fails. Retrieved and recorded on
2026-10-27 in the research stage of proper-study run 450355254538c1ba.

Each pull is reproduced byte for byte between its BEGIN and END lines, form feeds
included, except that one line feed is added before the END line: none of the four
extracts ends in a line feed, and each stated extract SHA-256 is of the bytes as the
tool emitted them, without that added line feed.
