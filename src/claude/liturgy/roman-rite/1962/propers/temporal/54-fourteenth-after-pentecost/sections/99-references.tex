\section*{References}

Only sources actually used above, with loci sufficient to check the claims made
from them. Evidence state is given where it limits what the source can support.
\textbf{Three witnesses named on page~2 are deliberately absent from this list}
--- Papias, Eusebius \work{Historia ecclesiastica} Book~III, and Jerome's
\work{Commentarii in epistolam ad Galatas} --- because this repository holds no
record of any of them in any form and nothing is asserted from any of them.
They are named in the page-2 row as bounded negatives, which is where an
unheld witness belongs; \textbf{a reference list is for sources used.} The same
holds for four instruments named above as not retrieved: Schuster's
\work{Liber Sacramentorum}, Hesbert's \work{Antiphonale Missarum Sextuplex},
Feltoe's edition of the Verona book, and Augustine's \work{Expositio ad
Galatas}.
