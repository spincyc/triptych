% Two-tier page-2 dossier table. This sheet makes three departures from the
% profile's fixed page-2 measurements; the note below \dossierprose lists all
% three together and states the escape clause that licenses them. The first of
% the three is the column widths set here. The profile fixes them at
% 0.14 / 0.18 / 0.35 / 0.16\linewidth; this table sets
% 0.13 / 0.16 / 0.22 / 0.32\linewidth. All four are changed, and the four
% widths still total 0.83 as the profile's do. The movement is into Date, and
% the reason is the chronology contract: the corpus answers the Epistle with
% four alternative labels and the Gospel and Communion with six, every one of
% them printed in the source's own words, so the Date cell of two dossiers
% carries several dates where the profile's measure assumes one. Proper,
% Citation and Location each give up measure, their detail belonging to the
% explanatory row beneath. The summary tier keeps \footnotesize, \arraystretch, \LTpre and \LTpost
% exactly as the profile sets them.

% Full-width explanatory and event rows inside a dossier.
%
% Measurement note. These are deliberate departures the profile provides for.
% The profile says to change its fixed page-2 measurements only when the
% complete inventory cannot remain legible after the hierarchy and the evidence
% have been preserved. That is this sheet's case: six dossiers carrying the
% evidence the research brief supplies for them will not stand on one physical
% page at the profile's measurements, and the alternatives the profile forbids
% are spilling, omitting evidence, or moving apparatus here from elsewhere.
%
% THREE of the profile's fixed measurements are varied on this sheet. These
% are all three of them, and nothing else the profile fixes is changed:
%
%   D1. Summary-tier column widths, set above at \dossiertable. Profile
%       0.14 / 0.18 / 0.35 / 0.16\linewidth; here
%       0.13 / 0.16 / 0.22 / 0.32\linewidth. All four change: 0.16\linewidth
%       moves into Date, donated by Proper, Citation and Location, because the
%       corpus answers two of the six dossiers with four and six alternative
%       labels respectively and every one of them is printed.
%   D2. Spanning explanatory and event row width. Profile 0.92\linewidth;
%       here 0.98\linewidth.
%   D3. Spanning-row font size. The profile sets the table in \footnotesize and
%       specifies no separate size for the spanning row, so the profile's value
%       for that row is \footnotesize --- 9pt on 11pt leading under the 11pt
%       base class in src/common/preamble.tex. Here it is \fontsize{6.4}{6.9}:
%       a reduction of roughly 29 percent in glyph size and 37 percent in
%       leading, below \scriptsize and nearer \tiny. This is a large departure
%       and is recorded as one.
%
% What the profile fixes and this sheet leaves alone: the two-tier hierarchy,
% the four summary fields, the \footnotesize summary tier, \arraystretch 1.02,
% \LTpre 0.15em, \LTpost 0pt, the 0.1em breathing space ending ordinary dossier
% rows, \cmidrule(lr){1-4} within a dossier with \midrule only between complete
% dossiers, and the italic event row set between two \cmidrule(lr){1-4} rules
% ahead of its explanation.
%
% D3 reached its present value in steps, and the history is recorded here so
% the increments are not mistaken for the departure. Every row must print a
% named bounded negative --- witnesses the repository does not hold in any
% form, held volumes with no registered passage locus, an unresolved-rights
% witness, and the absence of any modern critical horizon --- while the Date
% column now carries ten separate corpus labels across two dossiers, and a
% longtable row cannot break, so the sheet either fits whole or starts a second
% page the profile forbids. Successive unpublished revisions set 7.0/7.9 and
% then 6.9/7.5; this one sets 6.4/6.9. The departure that matters for review is
% the one against the profile's own \footnotesize, stated at D3 above, and not
% the last increment of it.
\newcommand{\dossierrowsize}{\fontsize{6.4}{6.9}\selectfont}
\newcommand{\dossierprose}[1]{\multicolumn{4}{@{}>{\raggedright\arraybackslash\dossierrowsize}p{0.98\linewidth}@{}}{#1}\\[0.1em]}
\newcommand{\dossierevent}[1]{\multicolumn{4}{@{}>{\raggedright\arraybackslash\dossierrowsize}p{0.98\linewidth}@{}}{\textit{#1}}\\}
