# Rubric Index

Every decision rule the publication states, mapped to its exact locus and graded. This index
and the publication's Section 13 concordance carry the same mapping; this file adds the
evidence state and the note.

Claim classes: **D** direct rule (the numbered rubric says it); **I** necessary inference
(follows from two or more direct rules, and is marked as an inference in the publication);
**W** editorial workflow (the project's method, not liturgical law).

`RG n` = *Rubricae generales*, 1962 Missal front matter. `RGMR n` = *Rubricae generales
Missalis Romani*, same. `RGBR n` = *Rubricae generales Breviarii Romani*, the second part (nn. 138–268), which the Missal omits; only RGBR 237–238 are used, cited from the *Acta*.
