# Saint Paul — chronology

Provider: Anthropic Claude. Every date is a claim with a stated basis.
Exactly one event in Paul's life is externally datable (the Gallio hearing,
via the Delphi inscription); every other date is a reconstruction hung
from it, from Gal 1–2's year-counts, and from Acts' blocks and officials.
The crucifixion alternative (30/33) propagates through all early dates.
This file and the publication's terminal chronology table state the same
claims.
