    Each entry gives an English name and, where the checked record supplies
    one, a Latin headword. A \textbf{Reader note} marks the preparation or
    recognition boundary supported for this audience; it is not a general
    direction for every ceremony or sacristy.
  \end{minipage}\hfill
  \begin{minipage}[t]{0.47\linewidth}
    \textbf{Representative, not universal.}\par
    Drawings teach recognition, not universal dimensions, ornament, material,
