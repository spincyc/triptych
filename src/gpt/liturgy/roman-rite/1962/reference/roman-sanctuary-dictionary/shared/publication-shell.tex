  \section{Questions for Priestly Review}
  Please annotate the object, variant, artwork, plate, and page IDs for every
  correction. Distinguish an observed defect from local preference.
  \begin{enumerate}
    \item Is each object correctly identified in English and Latin? Record any
      ambiguous or period-dependent term.
    \item Does the stated status match the cited 1962-horizon source?
    \item Is each object placed in the correct ritual, ministerial, and
      historical context?
    \item Does each drawing show physically possible construction, folds,
      parts, orientation, scale, and manner of use?
    \item Are substantive variants represented and named correctly?
    \item Could the intended reader confuse this object with another? What
      comparison or inset would prevent that confusion?
    \item Are handler, handoff, preparation, disposition, and ``do not
      handle'' statements accurate for this audience?
    \item Does any composition imply an impossible state, wrong minister,
      unsafe route, or local arrangement presented as universal?
    \item Is symbolism supported, proportionate, and distinct from rubric and
      function? \RSDAudienceReviewQuestion
    \item Which pages did you review at full size and in print, and which
      questions were outside your competence or remain unresolved?
  \end{enumerate}
