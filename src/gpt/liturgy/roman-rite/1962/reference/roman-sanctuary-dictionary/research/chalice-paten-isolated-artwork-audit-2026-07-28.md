# Isolated chalice and paten artwork audit

Audit date: 2026-07-28

## Result

Two new source-controlled drawings replace the former weak isolated studies
in generated dictionary entries:

- `RPD-FIG-sacred-vessels-0005-iso-chalice-v2.png` depicts only the chalice
  from Metropolitan Museum of Art object 463080.
- `RPD-FIG-sacred-vessels-0006-iso-paten-v2.png` depicts only the paten from
  the same cataloged set.

Each complete object is immediately recognizable at its rendered size. The
chalice drawing preserves the exemplar's broad cup, knop, architectural stem,
and lobed foot. The paten drawing preserves the shallow dish, broad rim,
recessed center, and thin edge. Neither drawing includes its companion,
another object, a host, cloth, person, hand, semantic mark, border, floor,
cast shadow, or rectangular background.

The existing catalog-exemplar comparison remains the one combined
prepared-chalice formation in the explicitly labelled bespoke altar-server
spread. The five generated editions select only the isolated chalice and
isolated paten drawings, so the paten entry does not repeat a second paten
thumbnail.

## Source and generation control

The checked Met Open Access image for object 463080 was supplied to both
generations. It controls only this paired catalog exemplar's visible
morphology. The 1962 *Missale Romanum* separately controls the prepared
paten-over-purificator-over-chalice relationship in the retained comparison
plate. Neither source makes the exemplar's ornament or proportions a
universal Roman prescription.

The canonical artwork manifest preserves both exact prompts, the unexposed
built-in generator identity, original chroma-key output identities, local
background-removal step, final normalized identities, corrections, source
ceiling, rights basis, consumer set, and review results.

## Boundary and technical review

The generated chroma backgrounds were not perfectly uniform despite the
prompt. Local background removal produced the checked alpha inputs without a
content edit. Each selected input was then stripped and converted to an
8-bit grayscale-plus-alpha publishing PNG. Transparent pixels replace the
former page rectangle, so the drawings blend with the TeX page ground.

The custody rows therefore declare
`boundary_treatment = "transparent"`. The artwork validator permits
grayscale-plus-alpha publication inputs only under that exact declaration;
legacy opaque 8-bit grayscale assets retain their existing rules.

At the declared maximum placements, both assets remain above 300 effective
DPI. Full-size inspection found clean subject isolation, complete contours,
generous padding, no green fringe visible on the page ground, and no
accidental crop, duplicate companion, text, watermark, or unsafe action.
