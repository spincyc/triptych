## Reader and purpose

This use-derived edition is for altar servers and those who train them. Its
eventual boundary remains everything a server may encounter, including objects
the server recognizes but does not handle. The current alpha is a bounded
44-record generated selection from the canonical inventory. Identity,
handling boundary, safety, and likely confusion form the visible teaching
structure.

Appearance never grants handling permission. A practical assignment or
ceremonial branch is not presented as a universal server action.
