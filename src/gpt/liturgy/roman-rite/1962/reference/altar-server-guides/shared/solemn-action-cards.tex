\flashback{SO-A09}{All roles}{1 SO-001--009 ready/enter; 2 SO-010--017 first

\flashback{SO-A12}{Every role with partner / MC}{Before moving, name giver,

charcoal. Never repair a miss with a rushed crossing.}
