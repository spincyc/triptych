Wave 1 corpus design review

This landing page is an index to the five governed design studies. The actual designs are exercised on the repository's generated private preview: the review harness loads a real preview route, then injects prototype.css and prototype.js into that page at runtime. The generated HTML, titles, metadata, absence states, rights explanations, anchors, and canonical PDF relationships remain the real inputs. The prototype files own presentation for review only.

01

Review locally, against a private preview

  1. From this checkout, run make public-preview.
  2. Run the fixed matrix through tools/tests/corpus_wave1_prototype_browser.mjs; its private review server mounts the preview below the real /triptych/ project prefix.
  3. Use this page as the review inventory; the route/state matrix and screenshot index, not this landing page, own the exact automated states.
  4. Inspect the generated files under build/public-alpha/preview/. Runtime injection does not rewrite them; a hard reload returns the untouched preview route.

These directions are intentionally local. This page offers no link to a hosted site, does not claim a production URL, and is excluded from the public-alpha browser-page and data-file maps.

03

The public projection is the fixture boundary

  • Review code reads generated files under build/public-alpha/preview/; it does not walk src/sources/ or infer redistribution rights from bytes found on disk.
  • No separate passage-text payload is generated for the selected rights-withheld fixture. Current edition projections still require a rights audit because other records' context or notes may contain source wording; the review matrix therefore does not use the known affected canon-7 record as a withholding oracle.
  • Catena chapter files remain spines. Commentary text is requested only for a selected fragment already present in the public projection, and offered Bible chapters are reached through the generated Bible manifest.
  • The Reader uses the generated reviewed HTML. No publication prose is copied into this directory, and the installed PDF remains the canonical printable edition.
  • The review layer makes no external asset or network request. Its stylesheet and script are the two sibling files named by this page.
