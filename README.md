# Fides, Cultus, Ius

*Catholic Studies in Faith, Worship, and Law*

`Fides, Cultus, Ius` is a source-audited library of printable Catholic study documents. Its scope includes guides to the variable parts of the Roman liturgy, expositions of the Ordinary and Order of Mass in multiple editions, sacramental and Mariological reference works, and discursive articles on faith, theology, and canon law. The canonical repository slug is `fides-cultus-ius`.

The collection is written for serious lay study, prayerful preparation, and verifiable research. It is not an official liturgical text, catechism, canonical opinion, or substitute for competent pastoral, theological, or legal counsel. Each document identifies whichever editions, jurisdictions, effective dates, and authorities govern its claims.

**Editorial status:** mixed-maturity working library. A tracked PDF records a reproducible publication state, not an assertion that the work has received ecclesiastical, theological, or canonical approval. Each collection profile defines its own evidence and review gates.

## Repository Model

Source and installed documents retain a provider branch. The current authored collection lives under `gpt`:

```text
src/gpt/
  common/                                      shared LaTeX infrastructure
  liturgy/roman-rite/
    1962/
      propers/temporal/<document>/
      propers/ritual/<document>/
      ordinary/<document>/
      reference/<document>/
    postconciliar/<edition-locale>/
      propers/<calendar-family>/<document>/   planned
      ordinary/<document>/                    planned
    comparative/<document>/                   planned
  theology/
    <document>/
    mariology/<document>/
    mariology/shared/                           optional shared sources
  articles/
    faith/<document>/                         planned
    canon-law/<document>/                     planned

doc/gpt/                                      tracked PDFs mirroring document paths
build/gpt/                                    transient build artifacts only
```

A document leaf contains `main.tex` and owns the research records required by its profile. Edition-neutral shared material belongs in an explicitly shared subtree; edition-specific text must not be silently reused across liturgical families. Directory names use stable source identities, not a civil-year occurrence schedule or an unqualified colloquial rite label.

See [the repository contract](guidance/repository.md) for naming, provenance, shared-fragment, and new-document rules.

## Build

```sh
make list       # discovered document IDs
make check-metadata # validate structured and inherited AI provenance
make            # build every PDF under build/
make install    # publish PDFs under tracked doc/
make clean      # remove only transient build artifacts
```

The Makefile discovers document leaves recursively from `src/gpt/**/main.tex`; adding a new document does not require extending a flat manifest. `doc/` mirrors the document hierarchy, while `build/` remains disposable and ignored.

## History and Repository Name

This library began as a set of traditional liturgical-year proper guides. Its existing commits retain that accurate narrower history. The transition to **Fides, Cultus, Ius** is recorded as an additive repository migration rather than by rewriting their accurate narrower record.

The checkout-directory and hosting-repository name are not part of committed history. Rename them to `fides-cultus-ius` outside this tree when desired, and update local remote URLs if applicable; no force-push or commit-hash rewrite is required.
