# trim-0001 visual review 02 — Pius IX Acta furniture-omitted variants

PASS: 11 assigned PDFs, 35 pages individually opened at full size; zero blocking findings. All are new inspections, with zero reused pages. Every document carried a `prior_finding`; each excluded raw OCR line is confirmed absent, each surrounding sentence reads continuously, and the added block break in `pius-ix-acta.volume-02.line-00028165.part-03.page-furniture-omitted-v2` now sets its page-foot note as a separate block. This report covers only lane 02 of batch `trim-0001` (Pius IX Acta, volumes II and III).

## Scope and method

Each assigned page PNG, produced by the repository's `pdf-review` tool, was opened as its own full-size image with the Read tool (1700×2200 rasters); no contact sheet, thumbnail or new raster pass was used. Displayed title, responsible issuer, act date and Latin label were compared with the frozen metadata. Headings, two-column flow, gutter, margins, glyphs, natural closing, historical notes and terminal source/rights apparatus were inspected on every page, with particular attention to folios, gathering signatures, page-foot marks, stamps and running heads inside the body, which the standing rulings make blocking in these boundary-reviewed series.

For each `prior_finding`, the named locus was located visually and the excluded raw OCR lines were confirmed absent. As supporting mechanical evidence only, the frozen manifest's `physical_line_ranges` were compared with the pinned container OCR text: every gap between selected ranges holds only digitizer marks, folios, gathering signatures, page-foot marks or stamps, except the disclosed duplicated scan in `pius-ix-acta.volume-03.line-00006552.part-01.duplicate-scan-omitted-v2`, whose excluded capture matches the retained capture line for line. `pdftotext` output of each PDF was consulted to confirm glyph identity (e.g. literal U+25A0) and single occurrence of formerly duplicated text. This is not word-level collation.

No source records, inventories, PDFs, tools, other lanes or shared caches were modified, and no state-changing git command was run. This report does not authorize installation or claim that installation, deployment, historical authentication or publication has occurred.
