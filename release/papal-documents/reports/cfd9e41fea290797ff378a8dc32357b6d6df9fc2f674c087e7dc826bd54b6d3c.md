## Re-issue note

This report replaces the first issue of this lane report, which marked `gregory-xvi-acta.volume-01.line-00065982.part-01` CHANGES_REQUIRED because its issuer line reads `ACTA GREGORII PP. XVI. @` (the volume running title plus an OCR speck). The batch coordinator then ruled that, for consistorial allocutions, the series accepts the volume running title as the documented issuer evidence (a shared running-header attribution). Under that ruling, an issuer line `ACTA GREGORII PP. XVI.` that matches the frozen metadata, with or without a stray OCR mark, is a nonblocking qualification. The precedent is `src/sources/papal-documents/historical-series-visual-29.md`, where `48 ACTA GREGORII PP. XVI.` passed, and lanes 03-05 of this batch passed the same pattern. No other blocking defect exists on that document, so it is now PASS with the qualification recorded below. No page was re-opened and no input changed. Only that page's ledger entry, this report and `result.json` were rewritten.

## Scope and method

Each assigned page PNG from the repository `pdf-review` raster run was opened as its own full-size image (1700x2200 original). No contact sheet, thumbnail, new rasterization, source acquisition, word-level collation, text correction or date reconstruction was performed. Rasters were hash-checked against the assignment immediately before each observation was recorded.

On every page the title line (title, responsible issuer, act date, language label) was compared with the frozen metadata, and headings, two-column flow, gutter, margins and glyphs were inspected for clipping, overlap, tofu or missing glyphs, collapsed tables and stranded headings. Natural source closing (dating clause, subscriptions, the source's own notes), modern digitizer signatures, running heads or page furniture interrupting the body, marginal summaries fused into body sentences, and raw placeholders such as `None` were checked. No assigned document carries a `prior_finding`.

This report is a layout and presentation review of uncorrected, uncollated historical OCR. It does not authorize or claim installation, publication, deployment, historical authentication or word-level fidelity.
